Research Question Tracker

What the app does
This app helps students organize research questions by recording why a question matters, its variables or measurements, and one limitation.

How to run it
Download research-planner.html from this repository and open it in a web browser.

What I tested
Adding a research question and checking that it appears.
Trying to submit an empty research question.
Refreshing the page to check whether entries remain saved.
Deleting an entry and checking that it disappears.

One limitation
The app is a basic local tool and does not share entries between different browsers or devices.

What I would build next
I would improve the layout and add clearer feedback to help users understand their saved research questions.
